# Media Bot

بوت تيليجرام لاستقبال روابط من المواقع التي يدعمها yt-dlp، مع اختيار جودة الفيديو أو استخراج الصوت.

## الملفات
- `main.py`: تشغيل خادم الويب واستقبال تحديثات تيليجرام.
- `config.py`: إعدادات البوت.
- `keyboards.py`: أزرار اختيار الجودة.
- `downloader.py`: تنزيل الوسائط ومعالجتها.
- `requirements.txt`: مكتبات بايثون.
- `Dockerfile`: تجهيز بيئة التشغيل وFFmpeg.

## إعداد Render
1. أنشئ Web Service واربطه بهذا المستودع.
2. اختر بيئة Docker.
3. أضف Environment Variable:
   - Key: `BOT_TOKEN`
   - Value: توكن البوت الجديد من BotFather (لا تشاركه مع أحد).
4. اترك `RENDER_EXTERNAL_URL` ليضبطه Render تلقائيًا.
5. انشر الخدمة.

## ملاحظات
- لا يوجد حد زمني ثابت للفيديو في هذا المشروع، لكن حجم الملف وقيود تيليجرام وموارد الاستضافة قد تمنع إرسال فيديو طويل.
- الدقة المتاحة تعتمد على الفيديو الأصلي والموقع.
- HDR يظهر فقط إذا كان المصدر يوفر مسار HDR مناسبًا؛ هذا الإصدار يختار أفضل جودة عامة ولا يضمن HDR.
- yt-dlp لا يدعم كل المواقع، وقد تتطلب بعض الروابط تسجيل دخول أو تكون محمية.
- استخدم البوت فقط مع المحتوى الذي تملكه أو لديك إذن بتنزيله. لا يزيل هذا المشروع العلامات المائية ولا يتجاوز قيود الوصول.
- الملفات المؤقتة تُنشأ على الخادم. في هذا الإصدار قد تبقى حتى يحذفها النظام؛ لا تستخدمه لتنزيل ملفات حساسة.
